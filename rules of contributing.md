# RULES OF CONTRIBUTION

## Section 1: Code Formatting
1. Use 4 spaces or 1 tab press for indentation.
2. Use snake_case for variable & function names.
3. Use ALL_CAPS for constants.
4. Write comments for all functions and complex code blocks.
5. Write **ONLY** assembly code in the AccidentalOS kernel *for now*. C is not allowed yet.
6. Follow the calling convention. Look at calling convention.md for reference.
7. Try not to use magic numbers, or if you do, define them as constants.
8. Keep your code readable and clean, and try to refactor when possible.

## Section 2: Git
1. Keep commit messages short yet descriptive.
2. Do not commit broken code unless it is a WIP to be fixed by others.
3. Test before committing whenever possible.
4. Make each commit do one logical change.
5. **NEVER** commit to the main branch. Always commit to a feature branch and make a pull request.

## Section 3. Other
1. **NEVER** modify my personal notes (notes to self.md). You can create your own note file on your local PC.
