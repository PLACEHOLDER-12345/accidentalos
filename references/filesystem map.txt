disk map of a floppy using the AOSFS

sector 0: boot code
sector 1: file header

char signature[4] = "AOSF"
char minor_version;
char major_version;
short ft_start;
short ft_sectors;
short data_start;

sectors 2-9: extent table

each extent is three shorts:

short sector_start; // what sector the data begins
short sector_count; // how many sectors long this extent is
short next_extent; // pointer to next extent

next_extent is an index into this table relative to the start of sector 2
if 0xFFFF, end of chain

sectors 10-24: file table

each file table entry = 32B

char name[16];
char ext[4];
short sector_start;
short sector_count;
char flags;
    DRWXHS??
    D = directory
    R = readable
    W = writeable
    X = executable
    H = hidden
    S = system file
    ? = reserved
char reserved;

short parent_entry_index;
int bytes;

dir-ID 0xFFFF means root

sectors 25+: data
